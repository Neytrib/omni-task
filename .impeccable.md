## Design Context

### Users
The creator specified a private task manager for individuals using Telegram text/voice capture and a web Kanban board on desktop and phone. Users review original content, create tasks, change status, and delete deliberately.

### Brand Personality
Clean productivity is the creator's requested tone. The post-S9 correction asks for a less boring, more responsive interface with visible drag/drop and interaction animation. Crisp, tactile and focused are the implementation interpretation; avoid marketing, decorative charts, unrelated features and fabricated sample tasks.

### Aesthetic Direction
Compact graphite/ivory workbench with citron primary controls, clear status lanes, readable sans-serif type and both light/dark themes. Purposeful card movement, drop-target feedback and short dialog/button/toast transitions honor reduced motion. Exact visual choices are delegated implementation decisions documented in DESIGN.md; this replaces the creator-rejected oversized serif/paper-and-ink treatment.

### Design Principles
1. Make real tasks the focus.
2. Preserve complete content and be honest about save/connection state.
3. Make every action usable by keyboard and on a phone.
4. Reuse working authentication and APIs.
5. Preserve completed live transport and task logic while improving presentation and motion.
